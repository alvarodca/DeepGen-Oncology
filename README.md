# Deep Generative Models for Single-Cell Oncology

This repository explores single-cell transcriptomics for personalised oncology. Single-cell RNA-seq measures gene expression across tens of thousands of cells. Data is high-dimensional, sparse and affected by technical and patient effects. We implement different methods such as PCA or variational autoencoders with count likelihoods (scVI) along with some others such as MrVI to obtain a low-dimensional latent space where cells can be clustered. 

The goal of this project is to assess how effectively deep generative latent spaces capture underlying transcriptional profiles and cell-type heterogeneity across breast cancer single cells while controlling for patient-level technical variation.
